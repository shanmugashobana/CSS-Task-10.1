# Student Registration Form

A simple student registration form built with **HTML** and **CSS**. It includes a form with common input types and a table showing dummy submitted student data.

## Features

- Form fields: Full Name, Email, Password, Gender, Skills, Date of Birth
- Different input types: text, email, password, radio buttons, checkboxes, date
- Built-in HTML validation (`required)
- Styled Register button with hover effect
- Input focus highlight
- "Submitted Students" table with dummy data

## Technologies Used

- HTML5
- CSS3
